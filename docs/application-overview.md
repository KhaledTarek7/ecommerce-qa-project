# Application Overview

## Project Name

**E-Commerce QA & Test Automation Project**

## Application Under Test

**SauceDemo / Swag Labs**

Website: https://www.saucedemo.com/

## Application Type

SauceDemo is a web-based demo e-commerce application that provides a simplified online shopping experience.

The application allows users to authenticate, browse products, view product information, add products to a shopping cart, complete a checkout workflow, and log out.

## Project Objective

The objective of this QA project is to validate the functional quality and reliability of the SauceDemo application while demonstrating a complete software testing lifecycle.

The project will cover:

- Requirement analysis
- Test planning
- Test strategy
- Manual functional testing
- Positive and negative testing
- Boundary and edge-case testing
- Test execution
- Defect reporting
- Regression testing
- Requirement traceability
- Test management using Jira and Zephyr
- UI automation using Selenium and pytest
- Page Object Model
- BDD using Behave and Gherkin
- CI/CD using GitHub Actions
- Test reporting

## Testing Approach

The application will primarily be tested using a black-box testing approach.

Testing will focus on observable application behavior from the user's perspective without relying on the internal implementation of the application.

## Requirement Source

SauceDemo does not provide a formal Business Requirements Document (BRD) or Software Requirements Specification (SRS) for this portfolio project.

Therefore, the project will use derived requirements based on:

- Observable application behavior
- Available application functionality
- Expected e-commerce behavior
- Documented QA assumptions

Any derived requirement will be documented clearly rather than presented as an official business requirement.

## Main User Flow

Login  
→ Product Listing  
→ Product Details / Product Selection  
→ Shopping Cart  
→ Checkout Information  
→ Checkout Overview  
→ Order Completion  
→ Logout

## Initial Functional Areas

1. Authentication / Login
2. Product Listing and Sorting
3. Product Details
4. Shopping Cart
5. Checkout Customer Information
6. Checkout Order Overview
7. Order Completion
8. Navigation, Menu, and Logout

## Initial Out of Scope

- Performance/load testing
- Security penetration testing
- Production infrastructure testing
- Real payment gateway testing
- Native mobile application testing
