# Requirements Traceability

This directory contains the Requirements Traceability Matrix (RTM) for the SauceDemo QA project.

The RTM provides end-to-end traceability between:

- Functional requirements
- Jira Stories
- Test scenarios
- Zephyr test cases
- Manual execution results
- Automation priorities
- Automation implementation status

The matrix is maintained throughout the project lifecycle and will be updated as automated regression coverage is implemented.

## Main Artifact

`requirements-traceability-matrix.xlsx`

The workbook contains:

- A project-level traceability dashboard
- Requirement-level traceability across all functional modules
- Jira Story and Zephyr Test Cycle references
- Manual execution status
- Automation candidate prioritization
