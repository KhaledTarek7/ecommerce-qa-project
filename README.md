# E-Commerce QA & Test Automation Project

A professional end-to-end Quality Assurance portfolio project based on the SauceDemo e-commerce web application.

## Project Objective

The objective of this project is to demonstrate a complete software testing lifecycle, including:

- Requirement analysis
- Test planning
- Test strategy
- Manual testing
- Test case design
- Defect management
- Jira and Zephyr
- Selenium automation
- pytest
- Page Object Model
- BDD with Behave
- GitHub Actions
- Test reporting
- Requirements traceability

## Application Under Test

**SauceDemo / Swag Labs**
